# Reference Projects and Gap Analysis

| Project | Strength to study | Opportunity for FraudSim Lab |
|---|---|---|
| [Santander gen-fraud-graph](https://github.com/SantanderAI/gen-fraud-graph) | Synthetic financial graph generation | Add cross-channel temporal scenarios and detector explanations |
| [Amazon Fraud Dataset Benchmark](https://github.com/amazon-science/fraud-dataset-benchmark) | Standardized datasets, splits and metrics | Connect benchmark inputs to controllable scenario generation |
| [NVIDIA financial-fraud-detection](https://github.com/NVIDIA-AI-Blueprints/financial-fraud-detection) | Reproducible fraud workflow example | Provide vendor-neutral baselines and scenario DSL |
| [Feedzai FIFAR dataset](https://github.com/feedzai/fifar-dataset) | Analyst prediction/capacity research | Simulate operational queues and analyst constraints |
| [SDV](https://github.com/sdv-dev/SDV) | Mature synthetic tabular data tooling | Add fraud-domain causality, campaigns and ground-truth lineage |

## Our wedge

Generate coherent fraud campaigns, not merely synthetic rows, then benchmark rules, graphs and models against known ground truth with drift and operational cost built in.
