# Roadmap

## Phase 0 — Data contract
- Define actor, account, device, merchant, event and label schemas.
- Publish scenario DSL, reproducibility rules and dataset card template.

## Phase 1 — Alpha scenario
- Account-takeover generator with configurable imbalance and temporal behavior.
- CSV/Parquet plus graph-edge exports.
- Transparent rules baseline and precision-recall report.

## Phase 2 — Fraud network lab
- Mule-ring and invoice-fraud scenarios.
- Graph benchmarks, drift controls and analyst-capacity simulation.
- Explainability and cost-sensitive evaluation.

## Phase 3 — Community benchmark
- Versioned scenario packs and challenge protocol.
- Model submissions with reproducible environments and result cards.

Release gates: deterministic seeds, leakage tests, privacy review and documented limitations.
